# Dure

You lead. Your agents work together.

Dure is an Agent Development Environment (ADE) for working with AI coding agents in one macOS workspace.

[Website](https://www.dureai.dev/) · [Documentation](https://docs.dureai.dev/en/introduction) · [Download for macOS](https://www.dureai.dev/download/mac/)
