title: "安装和更新 Dure"
description: "下载当前 Mac 测试版，准备智能体并保持应用更新。"
---

Dure 公开测试版支持 **Apple silicon Mac**。请准备已安装的编码智能体 CLI 和对应提供商账户。Dure 不包含模型订阅。

## 安装 Mac 应用

1. [下载最新版 macOS 版 Dure](https://www.dureai.dev/download/mac/)。
2. 打开 DMG，将 Dure 拖入“应用程序”。
3. 从“应用程序”打开 Dure。

此链接始终提供最新的 Mac 公开测试版。所下载版本的支持功能、签名与公证信息以及已知限制，请参阅[发行说明](https://github.com/hebbianai/dure/releases)。

### 通过命令行安装

如需不打开 DMG 直接安装同一测试版，请在终端运行：

```sh
curl -fsSL https://raw.githubusercontent.com/hebbianai/dure/main/scripts/install-macos.sh | sh
```

脚本会将下载的文件与发行版公布的摘要进行比对，并确认 macOS 接受 Dure 的签名和公证，然后安装当前公开测试版。安装位置是“应用程序”文件夹；如果您的账户无法写入该文件夹，则使用主目录中的“Applications”文件夹。`dure` 命令会添加到 `~/.local/bin`。如需使用其他文件夹，请将 `DURE_APP_INSTALL_DIR` 设置为绝对路径。如果已安装 Dure，请先退出。检查失败时，现有应用会保持不变。再次运行脚本即可替换为当前测试版。

### 通过 Homebrew 安装

如果您使用 [Homebrew](https://brew.sh)，请先信任一次 Dure 的 tap，然后安装 cask：

```sh
brew trust hebbianai/tap
brew install --cask hebbianai/tap/dure
```

对于官方仓库以外的 tap，Homebrew 只有在您信任该 tap 之后才会加载其中的 cask。如果 Homebrew 提示 `trust` 是未知命令，请先运行 `brew update`。cask 会将下载的文件与发行版公布的摘要进行比对，然后将当前公开测试版安装到“应用程序”文件夹。如果“应用程序”中已有 Dure，Homebrew 会停止而不会替换它；在安装命令中加上 `--adopt`，即可让 Homebrew 管理这个现有副本。

Dure 有自己的更新流程（见下文），因此普通的 `brew upgrade` 会跳过它。如需改用 Homebrew 更新，请指定 cask 名称：`brew upgrade --cask hebbianai/tap/dure`。

## 准备一个编码智能体

安装并登录你要使用的智能体。先在普通终端确认其命令可以启动，例如 `claude`、`codex` 或 `kimi`。Dure 的 **Settings → Agent CLI** 显示检测到的工具和可用设置操作。

提供商订阅、模型权限和使用费用与 Dure 分开。账户配置及终端/聊天支持见[编码智能体](/cn/providers)。

## 更新已有安装

打开 **Settings → General** 查看已安装版本，然后选择 **Check for updates**。有新测试版时，阅读提示并选择下载、安装操作。仅检查更新不会安装或重启应用。

不支持此更新流程的旧测试版需要手动替换一次：下载当前 DMG，退出旧应用，替换“应用程序”中的 Dure，再重新打开。更新前检查未完成的工作和[会话状态](/cn/session-model)。恢复与原进程持续运行是不同的情况。

<Accordion title="macOS 显示安全警告或应用已损坏">
  确认文件来自上面的官方下载链接。如果提示应用损坏，请重新下载并核对发行信息。按具体警告遵循 [Apple 指南](https://support.apple.com/en-us/102445)。不要关闭 macOS 安全保护，也不要强行打开被报告为恶意软件的文件。
</Accordion>
