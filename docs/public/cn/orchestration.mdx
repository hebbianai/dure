---
title: "通过消息和决策协调智能体"
description: "将 CLI 和 MCP 客户端连接到持久任务消息、人工决策与完成报告。"
---

智能体需要汇报进度、请求决策或返回分派任务的结果时，可使用 Dure 的协调集成。人的目标和工作范围始终是起点。

## 明确任务约定

说明目标、允许的修改、验证方式以及需要提问的时机。第二个智能体有独立范围时，可以并行调查或审查。

## 连接集成

先检查 Dure CLI 的全局集成状态。不加 `--global` 时，`dure integration status` 检查的是当前文件夹：

```sh
dure integration status --global
dure integration --help
```

将受支持的 Codex 和 Claude 发现条目安装到全局提供商配置：

```sh
dure integration install --global --approve-global-config
dure integration status --global
```

安装会修改提供商配置。阅读报告的变更，并用状态命令确认安装结果。此集成与选择编码智能体提供商或配置应用[插件](/cn/plugins)是分开的。

## 使用合适的交互

| 交互 | 用途 |
| --- | --- |
| Message | 本身不要求决策响应的进度、上下文、问题或结果 |
| Decision | 对分派任务的明确回答，使用文本或提供的选项 |
| 完成报告 | 任务结果、验证和剩余限制 |

CLI 和 MCP 集成提供这些交互及其事件。重新连接时，客户端从已确认的事件位置继续，因此不必把此前所有事件都当作新事件。

## 审查交接结果

检查修改文件和报告中的证据。回答请求的决策，或指引下一项任务。完成报告不会授权无关操作，也不能代替[审查](/cn/review-and-feedback)。

启动工作见 [CLI 执行与调度](/cn/cli-and-automation)，分开修改见[并行任务](/cn/first-parallel-workflow)。
