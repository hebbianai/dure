---
title: "VM 环境"
description: "在 Pro 中为工作树准备独立的计算环境。"
---

在支持 Pro 的 Dure 中启用 Pro 模式，通过项目配方创建 VM 或容器。配方在本机运行，返回 SSH 连接后，即可使用现有流程创建远程工作树和代理。

1. 在**添加代理**中选择本地 Git 项目，然后选择**使用 VM · Pro**。
2. 选择配方和名称，点击**准备环境**。配方使用本机凭据，可能创建收费资源，请先审阅脚本。
3. 运行后选择**在此环境中继续**，确认 SSH 主机密钥，然后创建远程工作树。
4. 在**设置 → VM 环境**中暂停、恢复或销毁。切换到 Basic 后仍可暂停和销毁已有环境。

关闭窗口不会停止准备。删除代理不会销毁 VM。请保存或推送所需更改后，显式销毁环境；销毁可能删除所有客户机文件并终止会话。

## 本地 Lima 示例

安装 Lima 1.2 或更高版本、Git 和 Python 3。将[配方](/examples/lima/lima.sh)保存为项目中的 `.dure/lima.sh`，将[清单](/examples/lima/dure.environments.json)保存为根目录的 `dure.environments.json`。

示例仅复制当前提交，不挂载主机目录，也不复制未提交更改或登录凭据。请在 VM 内安装代理 CLI 并登录。

有关配方协议、故障恢复和 CLI，请参阅[英文文档](/en/vm-environments#recipe-contract)。
