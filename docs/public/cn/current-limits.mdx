在熟悉的项目中使用当前测试版，并持续验证工作结果。[安装页面](/cn/install)提供当前下载和更新说明。

## 可用范围

| 领域 | 当前边界 |
| --- | --- |
| 公开下载 | Apple silicon Mac；Basic 界面，Pro 不可用 |
| 编码智能体 | 需要已安装 CLI 和提供商账户；能力因提供商和运行时而异 |
| GitHub | 侧栏需要桌面 `gh` 登录和仓库访问权限 |
| Diff 审查 | 本地 worktree；SSH 变更使用远程 Git |
| 调度工作 | 执行服务和主机必须保持可用 |
| 会话恢复 | 取决于保存状态和提供商支持；不会让进程跨重启存活 |

应用的七种显示语言与文档的四种发布语言是分开的。高级设置或集成控件可能因构建而异，请使用已安装应用显示的控件。

## 文件分离与权限

worktree 分开工作目录和分支，不隔离凭据、进程、网络访问或端口。两个 worktree 的变更合并时仍可能冲突。

提供商审批设置决定智能体能执行什么。按任务选择权限，并把有用的修改保存在版本控制中。

## 中断之后

应用断开连接不代表智能体已停止。重复命令前，检查已有会话、变更文件和外部影响。机器重启会结束原进程；受支持的[恢复](/cn/session-model)启动替代进程。

接受工作前检查变更和验证结果。继续阅读[审查与反馈](/cn/review-and-feedback)，或在不确定时查看[故障排查](/cn/troubleshooting)。
