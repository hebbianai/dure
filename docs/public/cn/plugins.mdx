title: "使用 Dure 插件"
description: "查找内置集成，检查兼容性，并为正确的工作区配置设置。"
---

Dure 插件提供 issue 跟踪视图、工作区设置等应用集成。打开侧栏的 **Plugin** 查看目录。Basic 界面也提供此入口。

## 检查集成

选择条目，查看描述、版本、安装状态和兼容性。**Built in** 表示随应用提供的包。目录也可能显示被拒绝的包或重复候选项；出现在列表中不代表已启用。

可用包发生变化后使用刷新控件。如果集成被拒绝或不兼容，请先阅读显示的原因。

## 选择正确的设置范围

打开所选集成的 **Plugin settings**。设置可能作用于用户或选定工作区；修改前检查范围和项目上下文。工作区设置需要先选中工作区。

例如，GitHub 提供工作区刷新间隔和默认 issue 列表。**GitHub** 侧栏用于打开仓库工作，**Plugin** 目录用于配置集成本身。

## 应用插件与智能体工具

| 位置 | 用途 |
| --- | --- |
| Plugin 侧栏 | Dure 集成目录、兼容性和设置 |
| GitHub 侧栏 | 仓库 issue、pull request、Projects 和任务启动 |
| Settings → Provider | 已安装的编码智能体 CLI 和提供商设置 |
| Settings → Agent tooling | Dure CLI、hook 和智能体集成设置 |

Dure 插件不会自动登录提供商账户或授予仓库权限。提供商扩展和 MCP 配置由各自工具管理。
