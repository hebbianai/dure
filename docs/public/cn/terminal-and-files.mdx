新智能体会在终端面板中打开，运行提供商的原生 CLI。你可以在 Dure 工作区中继续使用该工具的命令和快捷键。

## 在 shell 中运行检查

在智能体旁边打开普通终端面板。确认工作目录后，自己执行项目命令。例如 Node.js 项目可能使用：

```sh
pwd
ls
npm test
```

请使用仓库实际定义的命令。`npm test` 是示例，不是 Dure 的要求。

## 打开和编辑文件

通过项目文件浏览器在内置编辑器中打开文件。可以将其放在智能体或 [Diff 审查](/cn/review-and-feedback)旁边。自动保存选项位于 **Settings → General**。你与智能体修改同一文件时，请协调操作。

## 粘贴图片或拖入文件

将图片粘贴到智能体终端，或从 Finder 拖入文件。Dure 会准备供终端使用的文件路径；SSH 面板中则先上传，再插入远程路径。提供商决定是否以及如何使用附件。

等准备完成后再提交提示。传输失败时先解决错误。附加路径不会为提供商增加文件系统权限。

启动前，也可以将截图粘贴或拖入 **⌘N** 任务输入框。

## 终端或聊天视图

支持的提供商和运行时可通过面板上的 Terminal/Chat 控件切换交互视图。新智能体仍从终端启动。请查看[提供商能力](/cn/providers)，不要假定所有 CLI 的视图和恢复行为都相同。

字体大小与行高见[外观设置](/cn/settings)，远程文件准备见 [SSH 项目](/cn/remote-and-ssh)。
