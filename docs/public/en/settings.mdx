Open the gear in the sidebar for **Settings**. Choose **Basic** or **Beta** under **General → Interface mode**. Basic keeps the essential controls. Beta shows everything, including the **Terminal**, **Mobile**, **Shortcuts**, **Data locations** and **macOS permissions** pages.

## Find the setting you need

| Setting | Location |
| --- | --- |
| Basic or Beta interface | General |
| Installed app version and update check | General |
| Default provider and provider permission defaults | General |
| Display language and editor auto-save | General |
| Provider account profiles | AI provider accounts |
| CLI detection and provider setup | Agent CLI |
| Dure CLI and integration setup | Agent tooling |
| Theme, color schemes, terminal font and line height | Appearance |
| Claude/Codex top-bar usage indicators | Appearance → Status bar |
| Agent alerts and sound | Notifications |
| Activity and token usage from local provider logs | Stats and usage |
| Anonymous usage data switch, diagnostics and feedback facts ([details](/en/privacy-and-telemetry)) | Privacy and telemetry |

## Make terminal text comfortable

Use **A-** and **A+** in the top bar for terminal font size. Under **Appearance → Terminal font**, choose the font, adjust its size and set **Line height**. The preview helps you judge the spacing before returning to work.

These controls are available in Basic. Choose light, dark or system appearance and the corresponding workspace color scheme in the same page.

## Language and notifications

Choose the app language in **General**: English, Korean, Chinese, Japanese, Spanish, French or Portuguese. In **Notifications**, select the events and sounds that should get your attention, including how focused work is handled.

## Updates and provider choices

Use **General → Check for updates** to check the Mac app. Review and choose the offered download/installation actions; a check alone does not install or restart anything. Follow [Install and update Dure](/en/install) for older betas that require manual replacement.

Provider CLI updates and sign-in are separate from app updates. Use [coding agents and accounts](/en/providers) to select the provider/account, and choose permissions for the task rather than treating a workspace layout as a permission boundary.
