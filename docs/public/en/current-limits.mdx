Use the current beta on a familiar project and verify useful work as you go. The [installation page](/en/install) owns the current download and update instructions.

## Availability and capabilities

| Area | Current boundary |
| --- | --- |
| Public download | macOS on Apple silicon; Basic interface, with Pro unavailable |
| Coding agents | Installed CLI and provider account required; features vary by provider/runtime |
| GitHub | Desktop `gh` login and repository access required for the sidebar |
| Diff review | Local worktrees; use remote Git for SSH changes |
| Scheduled work | Execution service and host must remain available |
| Session recovery | Depends on saved state and provider support; it does not preserve a process across reboot |

The app's seven display languages and the documentation's four published languages are separate. Advanced settings or integration controls may differ by build; use the controls shown in the installed app.

## File separation and permissions

A worktree separates a working directory and branch. It does not isolate credentials, processes, network access or ports. Two worktrees can still produce conflicting changes when combined.

Provider approval settings determine what the agent may run. Choose them deliberately for the task, and keep useful changes in version control.

## After interruptions

A disconnected app is not evidence that its agent stopped. Inspect the existing session, changed files and external effects before repeating a command. A computer reboot ends the original process; [recovery](/en/session-model) starts a replacement when supported.

Check changes and verification results before accepting the work. Continue with [review and feedback](/en/review-and-feedback), or [troubleshooting](/en/troubleshooting) when something is unclear.
