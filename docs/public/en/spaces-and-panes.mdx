A **Space** is a named pane layout inside Dure. Use the top bar to keep stages such as Main and Review apart, and the sidebar to find the projects and agents you need.

| Item | What it organizes |
| --- | --- |
| Project | A local or SSH working folder |
| Agent/session | The running tool and its conversation |
| Pane | A view of an agent, shell, file or review |
| Space | A layout of panes, selected from Dure's top bar |

A Dure Space is separate from a macOS desktop. Moving a pane changes its view, not the agent's account, working directory or conversation.

## Create and switch Spaces

Use **+** in the top bar to add a Space. Select its tab or use **⌘1–⌘9** for the corresponding Space. Give Spaces names that help you return to the work.

## Split and balance panes

Right-click inside a terminal and choose **Split Right** or **Split Down** to open a new pane. Select an agent or terminal there. Use **Balance panes in current Space** in the top bar when the layout needs even sizes.

Splitting adds a view to the layout; choose a [dedicated worktree](/en/first-parallel-workflow) separately when the new task needs independent files.

## Move an existing pane

Drag its tab over the destination pane. Hold until **Split Right** or **Split Down** appears, then release over the highlighted target. You can also move panes between Spaces and open a session in a larger or dedicated window.

## Keep a review Space

For example, keep six working panes in Main and a shell, Claude Code and Codex in Review. Switch to Review to run checks, then return to Main.
