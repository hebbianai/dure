[Dure](https://www.dureai.dev/) is an agent development environment (ADE): a workspace for you and your AI coding agents. Run agents across projects and SSH hosts, keep their conversations and files close, and decide what to keep or change.

You set the goal and success criteria. Agents do the work with their native tools. Dure brings the sessions, working context and review surfaces together.

Dure is a workspace, not a coding model or a provider subscription. It works with native coding-agent CLIs such as Claude Code and Codex. Keep your existing provider accounts; subscriptions and usage charges remain separate from Dure. See [supported agents](/en/providers) for each provider's capabilities.

## Build a workflow around the task

Use a shell to run checks beside the agent, open files in the editor, and keep the goal and evidence in view. [Provider accounts](/en/providers), [SSH projects](/en/remote-and-ssh) and [plugins](/en/plugins) connect the tools you already use. [Settings](/en/settings) controls text, language and notifications.

For repeatable work, use [CLI runs and schedules](/en/cli-and-automation). For dispatched tasks that need structured messages and decisions, use [agent coordination](/en/orchestration).

Start with the [current Mac beta](/en/install), and read [its practical boundaries](/en/current-limits) before relying on unattended work.
