**Space** は Dure 内で名前を付けたペイン配置です。上部バーで Main、Review などの段階を分け、サイドバーから必要なプロジェクトとエージェントを探せます。

| 項目 | 整理する対象 |
| --- | --- |
| プロジェクト | ローカルまたは SSH の作業フォルダー |
| エージェント/セッション | 実行中のツールと会話 |
| ペイン | エージェント、シェル、ファイル、レビューの表示 |
| Space | Dure の上部バーから選ぶペイン配置 |

Dure の Space と macOS のデスクトップは別です。ペインを移動しても、エージェントのアカウント、作業ディレクトリ、会話は変わりません。

## Space を作成して切り替える

Space を追加するには、上部バーの Space タブの末尾にある **+**（ツールチップは **New desktop (⌘⇧T)**）を選ぶか **⌘⇧T** を押し、名前を入力して **Enter** を押します。タブを選ぶか **⌘1–⌘9** で対応する Space に切り替えてください。作業に戻りやすい名前を付けましょう。

## ペインの分割と均等配置

ターミナル内を右クリックして **Split Right** または **Split Down** を選び、新しいペインを開きます。そこでエージェントかターミナルを選択します。サイズを均等にしたいときは、同じターミナルのメニューか現在の Space タブの右クリックメニューで **Balance panes in current Space** を選ぶか、**⌘⇧B** を押します。

分割は配置に表示を追加する操作です。新しいタスクのファイルを分ける場合は、[専用 worktree](/jp/first-parallel-workflow)を別に選んでください。

## 既存のペインを移動する

タブを移動先のペインにドラッグし、**Split Right** または **Split Down** が表示されるまで待ってから、強調された領域にドロップします。Space 間でペインを移動したり、セッションを大きなウィンドウや独立したウィンドウで開いたりすることもできます。

## レビュー用の Space を用意する

例えば Main に六つの作業ペイン、Review にシェル、Claude Code、Codex を配置できます。Review で検証してから Main に戻りましょう。
