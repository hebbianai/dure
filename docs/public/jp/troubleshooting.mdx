---
title: "トラブルシューティング"
description: "ツールの検出、GitHub アクセス、更新、中断した作業について確認します。"
---

具体的な失敗と、選択したプロジェクト、ホスト、プロバイダーから確認します。同じタスクを何度も始めるより、エラーメッセージを残してください。

## エージェントがない、または開始できない

通常のターミナルで CLI を試し、**Settings → Agent CLI** の検出結果と設定案内を確認します。シェルの `PATH` を変えた場合は、Dure を開き直して環境を読み込みます。SSH 作業ではリモートマシンでも確認してください。

認証が必要ならログインし、アカウントがそのツールやモデルを使えるか確認します。Dure はプロバイダー認証情報を提供しません。

## GitHub にリポジトリがない、またはアクセスエラーになる

GitHub remote のあるローカル Git プロジェクトを選び、デスクトップの GitHub CLI を確認します。

```sh
gh auth status
git remote -v
```

ログイン中のアカウントがリポジトリを読めるか確認し、サイドバーを更新してください。組織や Projects の権限エラーには該当する GitHub 権限が必要です。[GitHub の作業フロー](/jp/github-workflows)を参照できます。

## 設定やプラグインが見つからない

Basic と Beta の現在の配置は[設定ガイド](/jp/settings)で確認します。サイドバーの **Plugins** で互換性と設定を確認し、一覧を更新してください。拒否・競合したパッケージは有効な統合ではありません。[プラグイン](/jp/plugins)を参照してください。

## タスクが切断または終了したように見える

別のタスクを開始する前に[セッション状態](/jp/session-model)と実際のファイルを確認します。稼働中なら再接続し、プロセス終了後なら提示された復旧を使います。外部操作を繰り返さないよう、完了済みの内容を記録してください。

## 添付が届かない

準備とアップロードが終わってから送信します。ペインのホスト、パス、転送エラーを確認し、失敗した添付を再試行してください。画像対応はプロバイダーにより異なります。[ターミナルの添付](/jp/terminal-and-files)を参照してください。

## 更新や macOS での起動に失敗する

**Settings → General** でバージョンを確認します。更新確認が失敗したら **Check for updates** を再試行するか、[Dure のインストール](/jp/install)にある公式 DMG を使います。確認だけではインストールされません。

macOS の警告では公式のダウンロードか確認し、[Apple の案内](https://support.apple.com/en-us/102445)に従ってください。保護機能を無効にしたり、マルウェアと報告されたファイルを強制的に開いたりしないでください。

## 役立つ報告を集める

アプリのバージョン、プロバイダーと CLI のバージョン、ローカル/SSH の区別、正確な操作とエラーを含めます。**Settings → Privacy and telemetry** では、診断レポートの内容を確認してから、コピー、保存、Dure チームへの送信を選べることを案内しています。[プライバシーページ](/jp/privacy-and-telemetry)には、アプリが送信できる匿名の使用データとオフにする方法をまとめています。共有前に認証情報、私的なパス、無関係な会話を取り除いてください。
