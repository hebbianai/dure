使い慣れたプロジェクトから始めましょう。一つのエージェントに明確なタスクを渡し、結果を読んで次の行動を決めます。先に [Dure をインストール](/jp/install)し、エージェントの CLI にログインしてください。

## 1. プロジェクトを開く

Dure にローカルのプロジェクトフォルダーを追加します。Git リポジトリなら worktree と変更レビューを利用できます。意図したフォルダーで作業できるよう、開始前にプロジェクトを選びます。

既存の会話があれば、初期設定のインポートプレビューで会話を選び、Space とペインの配置を調整してから確定できます。インポートを省略して新しいタスクを始めても構いません。

## 2. ⌘N でタスクを説明する

**⌘N** で **New agent** を開きます。プロジェクトとプロバイダーを選び、次のように依頼します。

```text
このプロジェクトのテスト実行方法を調べ、該当するコマンドを実行してください。
ファイルは変更せず、結果と実行できなかった検証を報告してください。
```

独立して編集するタスクでは **Isolate in a dedicated worktree** を有効にします。開始前にアカウントと詳細なモデル・権限設定を確認してください。worktree はファイルを分けますが、エージェントの権限は制限しません。

## 3. 開始して結果を確認する

**Enter** または **Start agent** で開始します。プロバイダーのネイティブ CLI がターミナルペインで開きます。必要なログインや承認を行い、報告された結果と参照されたファイルを確認してください。

編集タスクでは [Diff レビュー](/jp/review-and-feedback)を開き、実際の変更とテスト結果を確認します。同じ会話で修正点や次のタスクを伝えます。

## 4. 必要に応じてエージェントを追加する

今作成したペインのターミナル内を右クリックします。**Split Down** または **Split Right** を選び、新しいペインで次のエージェントを選択してください。

並行編集には[独立した worktree](/jp/first-parallel-workflow)を使います。[GitHub サイドバー](/jp/github-workflows)の issue や pull request で **Start** を選ぶこともできます。

配置の調整は [Space とペイン](/jp/spaces-and-panes)、既存の会話への復帰は[セッションと復旧](/jp/session-model)を参照してください。
