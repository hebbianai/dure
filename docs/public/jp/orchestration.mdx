---
title: "メッセージと判断でエージェントを連携させる"
description: "CLI と MCP を、永続的なメッセージ、ユーザーの判断、完了報告につなげます。"
---

進捗報告、判断の依頼、割り当てたタスクの結果返却には、Dure の連携機能を使えます。出発点はユーザーの目標と作業範囲です。

## 作業の合意を明確にする

目標、許可された変更、検証方法、質問が必要な時点を示します。独立した範囲なら、別のエージェントが調査やレビューを並行して行えます。

## 統合を接続する

先に Dure CLI のグローバルな統合状態を確認します。`--global` を付けない `dure integration status` は現在のフォルダーを確認します。

```sh
dure integration status --global
dure integration --help
```

対応する Codex と Claude の検出項目を、グローバルなプロバイダー設定にインストールするには次を実行します。

```sh
dure integration install --global --approve-global-config
dure integration status --global
```

インストールはプロバイダー設定を変更します。報告された変更を読み、状態コマンドで結果を確認してください。プロバイダー選択やアプリの[プラグイン](/jp/plugins)設定とは別です。

## 適切なやり取りを選ぶ

| やり取り | 目的 |
| --- | --- |
| Message | 明示的な決定への応答を必要としない進捗、文脈、質問、結果 |
| Decision | 割り当てられたタスクへの明示的な回答。テキストか提示された選択肢を使用 |
| 完了報告 | タスク結果、検証、残っている制限 |

CLI と MCP 統合はこれらのやり取りとイベントを公開します。再接続時は確認済みイベント位置から再開できるため、以前の全イベントを新規として処理する必要はありません。

## 引き継がれた結果を確認する

変更ファイルと報告された根拠を確認してください。求められた判断に答えるか、次のタスクを指示します。完了報告は無関係な操作への承認や[レビュー](/jp/review-and-feedback)の代わりにはなりません。

開始方法は [CLI 実行とスケジュール](/jp/cli-and-automation)、編集の分離は[並行タスク](/jp/first-parallel-workflow)を参照してください。
