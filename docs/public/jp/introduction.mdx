[Dure](https://www.dureai.dev/) は、人と AI コーディングエージェントが共同作業するエージェント開発環境（ADE、Agent Development Environment）です。複数のプロジェクトや SSH ホストでエージェントを動かし、会話とファイルを近くに置いて、何を残し何を変えるかを決めます。

人が目標と成功条件を定め、エージェントは使い慣れたツールで実行します。Dure がセッション、作業の文脈、レビュー画面をつなぎます。

Dure はワークスペースであり、コーディングモデルや provider のサブスクリプションではありません。Claude Code や Codex などのネイティブ CLI と既存のアカウントを使い、provider の契約や利用料金は Dure と別になります。エージェントごとの機能は[対応エージェント](/jp/providers)を確認してください。

## タスクに合わせた進め方を作る

エージェントの隣でシェルによる検証を実行し、エディターでファイルを開いて、目標と根拠を確認しましょう。[プロバイダーアカウント](/jp/providers)、[SSH プロジェクト](/jp/remote-and-ssh)、[プラグイン](/jp/plugins)で既存のツールをつなげます。[設定](/jp/settings)では文字、言語、通知を調整できます。

繰り返す作業には [CLI 実行とスケジュール](/jp/cli-and-automation)を使います。割り当てたタスクに構造化されたメッセージや明示的な判断が必要なら、[エージェントの連携](/jp/orchestration)を利用できます。

[現在の Mac ベータ版](/jp/install)から始め、無人実行に頼る前に[利用上の制限](/jp/current-limits)を確認してください。
