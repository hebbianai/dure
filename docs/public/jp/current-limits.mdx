使い慣れたプロジェクトで現在のベータ版を使い、成果を検証しながら進めてください。現在のダウンロードと更新手順は[インストールページ](/jp/install)にあります。

## 利用できる範囲

| 項目 | 現在の範囲 |
| --- | --- |
| 公開ダウンロード | Apple silicon Mac、Basic インターフェース。Pro は利用不可 |
| コーディングエージェント | インストール済み CLI とアカウントが必要。機能はプロバイダーとランタイムに依存 |
| GitHub | サイドバーにはデスクトップの `gh` ログインとリポジトリ権限が必要 |
| Diff レビュー | ローカル worktree 用。SSH の変更はリモート Git を使用 |
| 定期実行 | 実行サービスとホストが利用可能であることが必要 |
| セッション復旧 | 保存状態とプロバイダー対応に依存。再起動をまたいで元のプロセスを維持しない |

アプリの表示言語七つと公開文書の言語四つは別です。詳細設定や統合コントロールはビルドで異なる場合があるため、インストール済みアプリの表示に従ってください。

## ファイル分離と権限

worktree は作業ディレクトリとブランチを分けます。認証情報、プロセス、ネットワーク、ポートは隔離しません。二つの worktree の変更を統合すると競合する可能性があります。

エージェントが実行できる操作はプロバイダーの承認設定によって決まります。タスクに合わせて選び、有用な変更はバージョン管理に残してください。

## 中断後の確認

アプリの切断はエージェントの停止を意味しません。コマンドを繰り返す前に既存のセッション、変更ファイル、外部への影響を確認してください。再起動で元のプロセスは終了し、対応する[復旧](/jp/session-model)で代替プロセスが始まります。

成果を受け入れる前に変更と検証結果を確認します。[レビューとフィードバック](/jp/review-and-feedback)、または不明点があれば[トラブルシューティング](/jp/troubleshooting)に進んでください。
