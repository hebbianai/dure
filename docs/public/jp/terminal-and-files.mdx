新しいエージェントは既定でターミナルペインで開きます。プロバイダーのネイティブ CLI を使うため、そのツールのコマンドやショートカットを Dure の作業画面でも利用できます。

## シェルで検証する

エージェントの隣に通常のターミナルペインを開きます。作業フォルダーを確認し、プロジェクトのコマンドを自分で実行してください。Node.js プロジェクトなら、次のような例が考えられます。

```sh
pwd
ls
npm test
```

実際のリポジトリで定義されたコマンドを使ってください。`npm test` は例であり、Dure の必須コマンドではありません。

## ファイルを開いて編集する

プロジェクトのファイルエクスプローラーから、内蔵エディターでファイルを開きます。エージェントや [Diff レビュー](/jp/review-and-feedback)の隣に配置できます。自動保存は **Settings → General** で確認し、同じファイルをエージェントと編集する場合は調整してください。

## 画像を貼り付け、ファイルをドロップする

エージェントのターミナルに画像を貼り付けるか、Finder からファイルをドロップします。Dure はターミナル用のパスを準備し、SSH ペインでは先にアップロードしてからリモートパスを挿入します。添付を利用できるか、どう扱うかはプロバイダーによって異なります。

準備が完了してからプロンプトを送信してください。転送に失敗した場合は先にエラーを解決します。パスを添付しても、プロバイダーのファイル権限が増えることはありません。

開始前の **⌘N** タスク入力欄にも、スクリーンショットを貼り付けたりドロップしたりできます。

## ターミナルとチャット表示

Beta インターフェースでは、対応するプロバイダーとランタイムのペインで Terminal/Chat コントロールを使って表示を切り替えられます。**Settings → General → Default agent pane** で Chat を選ばない限り、新規エージェントはターミナルで開始します。Basic では各エージェントが開いたときの表示のままです。すべての CLI が同じ表示や再開方法に対応するとは限らないため、[プロバイダーの機能](/jp/providers)を確認してください。

文字サイズと行高は[外観設定](/jp/settings)、リモートファイルの準備は [SSH プロジェクト](/jp/remote-and-ssh)を参照してください。
