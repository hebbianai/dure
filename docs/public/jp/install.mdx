Dure の公開ベータ版は **Apple silicon 搭載 Mac** で利用できます。コーディングエージェントの CLI とプロバイダーアカウントを用意してください。Dure にモデルのサブスクリプションは含まれません。

## Mac アプリをインストールする

1. [macOS 用 Dure の最新版をダウンロード](https://www.dureai.dev/download/mac/)します。
2. DMG を開き、Dure を「アプリケーション」にドラッグします。
3. 「アプリケーション」から Dure を開きます。

このリンクから最新の Mac 公開ベータ版を入手できます。ダウンロードしたバージョンの対応機能、署名・公証の情報、既知の制限は[リリースノート](https://github.com/hebbianai/dure/releases)を確認してください。

### コマンドラインからインストールする

DMG を開かずに同じベータ版をインストールするには、ターミナルで次を実行します。

```sh
curl -fsSL https://raw.githubusercontent.com/hebbianai/dure/main/scripts/install-macos.sh | sh
```

スクリプトは、ダウンロードしたファイルをリリースで公開されたダイジェストと照合し、Dure の署名と公証を macOS が受け入れることを確認してから、現在の公開ベータ版をインストールします。インストール先は「アプリケーション」フォルダです。アカウントにこのフォルダへの書き込み権限がない場合は、ホームディレクトリの「Applications」フォルダを使います。`dure` コマンドは `~/.local/bin` に追加されます。別のフォルダを使うには、`DURE_APP_INSTALL_DIR` に絶対パスを指定してください。すでにインストールしている場合は、先に Dure を終了してください。確認に失敗した場合、既存のアプリはそのまま残ります。スクリプトをもう一度実行すると、現在のベータ版に置き換わります。

### Homebrew でインストールする

[Homebrew](https://brew.sh) を使っている場合は、Dure の tap を一度信頼してから cask をインストールします。

```sh
brew trust hebbianai/tap
brew install --cask hebbianai/tap/dure
```

Homebrew は、公式リポジトリ以外の tap にある cask を、その tap を信頼するまで読み込みません。`trust` が不明なコマンドだと表示された場合は、先に `brew update` を実行してください。cask は、ダウンロードしたファイルをリリースで公開されたダイジェストと照合してから、現在の公開ベータ版を「アプリケーション」フォルダにインストールします。「アプリケーション」に Dure がすでにある場合、Homebrew は置き換えずに停止します。インストールコマンドに `--adopt` を付けると、既存のアプリを Homebrew で管理できます。

Dure には独自の更新手順（後述）があるため、通常の `brew upgrade` では Dure はスキップされます。Homebrew で更新する場合は、cask を指定して `brew upgrade --cask hebbianai/tap/dure` を実行してください。

## コーディングエージェントを準備する

使うエージェントをインストールしてログインします。通常のターミナルで `claude`、`codex`、`kimi` などのコマンドが起動するか確認してください。Dure の **Settings → Agent CLI** に検出結果と設定操作が表示されます。

プロバイダーの契約、モデルへのアクセス、利用料金は Dure とは別です。アカウントプロファイルとターミナル/チャット対応は[コーディングエージェント](/jp/providers)を参照してください。

## インストール済みのアプリを更新する

**Settings → General** で現在のバージョンを確認し、**Check for updates** を選びます。新しいベータ版があれば案内を読み、ダウンロードとインストールを選択します。確認だけではインストールや再起動は行われません。

この更新フローに対応していない旧ベータ版は、一度手動で置き換える必要があります。現在の DMG をダウンロードし、旧アプリを終了して「アプリケーション」の Dure を置き換え、再度開いてください。更新前に未完了の作業と[セッション状態](/jp/session-model)を確認します。復旧は、同じプロセスが動き続けることとは異なります。

<Accordion title="macOS にセキュリティやアプリ破損の警告が出る場合">
  上記の公式リンクから取得したファイルか確認してください。破損の警告であれば再ダウンロードし、リリース情報と照合します。警告に応じて [Apple の案内](https://support.apple.com/en-us/102445)に従ってください。macOS の保護機能を無効にしたり、マルウェアと報告されたファイルを強制的に開いたりしないでください。
