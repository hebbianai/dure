Dure 공개 베타는 **Apple silicon Mac**에서 사용할 수 있습니다. 코딩 에이전트 CLI와 해당 제공자 계정을 준비하세요. Dure에는 모델 구독이 포함되어 있지 않습니다.

## Mac 앱 설치

1. [최신 macOS용 Dure 다운로드](https://www.dureai.dev/download/mac/).
2. DMG를 열고 Dure를 응용 프로그램 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 Dure를 실행합니다.

이 링크는 최신 공개 Mac 베타를 제공합니다. 다운로드한 버전의 지원 기능, 서명·공증 정보와 알려진 제한은 [릴리스 노트](https://github.com/hebbianai/dure/releases)에서 확인하세요.

### 명령줄로 설치

DMG를 열지 않고 같은 베타를 설치하려면 터미널에서 다음을 실행합니다.

```sh
curl -fsSL https://raw.githubusercontent.com/hebbianai/dure/main/scripts/install-macos.sh | sh
```

스크립트는 다운로드한 파일을 릴리스에 게시된 다이제스트와 대조하고, macOS가 Dure의 서명과 공증을 승인하는지 확인한 뒤 현재 공개 베타를 설치합니다. 설치 위치는 **응용 프로그램** 폴더이며, 계정에 이 폴더의 쓰기 권한이 없으면 홈 디렉터리의 **Applications** 폴더를 사용합니다. `dure` 명령은 `~/.local/bin`에 추가됩니다. 다른 폴더에 설치하려면 `DURE_APP_INSTALL_DIR`을 절대 경로로 지정하세요. 이미 설치되어 있다면 먼저 Dure를 종료하세요. 확인에 실패하면 기존 앱은 그대로 유지됩니다. 스크립트를 다시 실행하면 현재 베타로 교체됩니다.

### Homebrew로 설치

[Homebrew](https://brew.sh)를 사용한다면 Dure tap을 한 번 신뢰한 뒤 cask를 설치합니다.

```sh
brew trust hebbianai/tap
brew install --cask hebbianai/tap/dure
```

Homebrew는 공식 저장소 밖의 tap에 있는 cask를 그 tap을 신뢰하기 전까지 불러오지 않습니다. `trust`가 알 수 없는 명령이라고 나오면 먼저 `brew update`를 실행하세요. cask는 다운로드한 파일을 릴리스에 게시된 다이제스트와 대조한 뒤 현재 공개 베타를 **응용 프로그램** 폴더에 설치합니다. **응용 프로그램**에 Dure가 이미 있으면 Homebrew는 교체하지 않고 멈춥니다. 설치 명령에 `--adopt`를 붙이면 기존 앱을 Homebrew가 관리하게 할 수 있습니다.

Dure에는 자체 업데이트 흐름(아래 설명)이 있어 일반 `brew upgrade`는 Dure를 건너뜁니다. Homebrew로 업데이트하려면 cask를 지정해 `brew upgrade --cask hebbianai/tap/dure`를 실행하세요.

## 코딩 에이전트 준비

사용할 에이전트를 설치하고 로그인합니다. 일반 터미널에서 `claude`, `codex`, `kimi` 등 해당 명령이 실행되는지 확인하세요. Dure의 **Settings → Agent CLI**에서 감지된 도구와 설정 동작을 볼 수 있습니다.

제공자 구독, 모델 접근 권한과 사용 요금은 Dure와 별개입니다. 계정 프로필과 터미널/채팅 지원은 [코딩 에이전트](/ko/providers)를 참고하세요.

## 기존 설치 업데이트

**Settings → General**에서 설치된 버전을 확인하고 **Check for updates**를 선택하세요. 새 베타가 있으면 안내를 읽고 다운로드와 설치를 진행합니다. 업데이트 확인만으로 설치하거나 앱을 재시작하지는 않습니다.

이 업데이트 흐름이 없는 이전 베타는 한 번 수동으로 교체해야 합니다. 현재 DMG를 내려받고 기존 앱을 종료한 뒤 응용 프로그램 폴더의 Dure를 교체하고 다시 실행하세요. 업데이트 전에는 진행 중인 작업과 [세션 상태](/ko/session-model)를 확인하세요. 복구는 같은 프로세스의 연속 실행과 다릅니다.
