Dure 공개 베타는 **Apple silicon Mac**에서 사용할 수 있습니다. 코딩 에이전트 CLI와 해당 제공자 계정을 준비하세요. Dure에는 모델 구독이 포함되어 있지 않습니다.

## Mac 앱 설치

1. [최신 macOS용 Dure 다운로드](https://www.dureai.dev/download/mac/).
2. DMG를 열고 Dure를 응용 프로그램 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 Dure를 실행합니다.

이 링크는 최신 공개 Mac 베타를 제공합니다. 다운로드한 버전의 지원 기능, 서명·공증 정보와 알려진 제한은 [릴리스 노트](https://github.com/hebbianai/hebbian-releases/releases)에서 확인하세요.

## 코딩 에이전트 준비

사용할 에이전트를 설치하고 로그인합니다. 일반 터미널에서 `claude`, `codex`, `pi` 등 해당 명령이 실행되는지 확인하세요. Dure의 **Settings → Provider**에서 감지된 도구와 설정 동작을 볼 수 있습니다.

제공자 구독, 모델 접근 권한과 사용 요금은 Dure와 별개입니다. 계정 프로필과 터미널/채팅 지원은 [코딩 에이전트](/ko/providers)를 참고하세요.

## 기존 설치 업데이트

**Settings → General**에서 설치된 버전을 확인하고 **Check for updates**를 선택하세요. 새 베타가 있으면 안내를 읽고 다운로드와 설치를 진행합니다. 업데이트 확인만으로 설치하거나 앱을 재시작하지는 않습니다.

이 업데이트 흐름이 없는 이전 베타는 한 번 수동으로 교체해야 합니다. 현재 DMG를 내려받고 기존 앱을 종료한 뒤 응용 프로그램 폴더의 Dure를 교체하고 다시 실행하세요. 업데이트 전에는 진행 중인 작업과 [세션 상태](/ko/session-model)를 확인하세요. 복구는 같은 프로세스의 연속 실행과 다릅니다.

<Accordion title="macOS에 보안 경고나 앱 손상 경고가 표시될 때">
  위 공식 링크에서 받은 파일인지 확인하세요. 앱이 손상되었다는 경고라면 새로 다운로드하고 릴리스 정보를 대조하세요. 경고 내용에 맞는 [Apple 안내](https://support.apple.com/en-us/102445)를 따르세요. macOS 보안 기능을 끄거나 악성 소프트웨어로 표시된 파일을 강제로 열지 마세요.
</Accordion>
