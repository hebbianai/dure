익숙한 프로젝트에서 현재 베타를 사용하고 결과를 검증하며 진행하세요. 현재 다운로드와 업데이트 절차는 [설치 안내](/ko/install)에서 관리합니다.

## 사용 가능 범위

| 영역 | 현재 범위 |
| --- | --- |
| 공개 다운로드 | Apple silicon Mac. **Settings → General → Interface mode**에서 Basic 또는 Beta 선택 |
| Basic 인터페이스 | 필수 pane 컨트롤. 런처에서 Claude Code, Codex, Kimi Code 제공 |
| Beta 인터페이스 | 등록된 모든 에이전트 CLI, Terminal/Chat 전환, 자동 계정 복구, VM 환경, Automations 추가 |
| 코딩 에이전트 | 설치된 CLI와 제공자 계정 필요. 제공자·런타임별 기능 차이 |
| GitHub | 사이드바에 데스크톱 `gh` 로그인과 저장소 접근 권한 필요 |
| Diff 리뷰 | 로컬 worktree용. SSH 변경은 원격 Git 사용 |
| 예약 작업 | 실행 서비스와 호스트를 사용할 수 있어야 함 |
| 세션 복구 | 저장 상태와 제공자 지원에 따라 다름. 재부팅 전 프로세스를 유지하지 않음 |

앱의 표시 언어 7개와 공개 문서 언어 4개는 별개입니다. Beta에서는 Basic이 숨기는 고급 설정 페이지와 pane 컨트롤도 표시되므로, 선택한 인터페이스에 표시된 기능을 사용하세요.

## 파일 분리와 권한

worktree는 작업 폴더와 브랜치를 분리합니다. 자격 증명, 프로세스, 네트워크 접근, 포트를 격리하지는 않습니다. 두 worktree의 변경을 합치면 충돌할 수 있습니다.

에이전트가 실행할 수 있는 동작은 제공자 승인 설정에 따라 달라집니다. 작업에 맞게 선택하고 유용한 변경은 버전 관리에 남기세요.

## 중단 이후

앱 연결이 끊겼다고 에이전트가 멈춘 것은 아닙니다. 명령을 반복하기 전에 기존 세션, 변경 파일과 외부 시스템에 반영된 결과를 확인하세요. 컴퓨터를 재부팅하면 원래 프로세스는 종료되며 지원되는 [복구](/ko/session-model)는 새 프로세스를 시작합니다.

결과를 받아들이기 전에 변경과 검증 근거를 확인하세요. [리뷰와 피드백](/ko/review-and-feedback) 또는 [문제 해결](/ko/troubleshooting)로 이어가세요.
