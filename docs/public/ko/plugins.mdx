Dure 플러그인은 이슈 트래커 화면이나 작업 공간 설정 같은 앱 통합을 제공합니다. 사이드바의 **Plugins**에서 목록을 열 수 있으며 Basic과 Beta 인터페이스 모두에서 사용할 수 있습니다.

## 통합 확인

항목을 선택해 설명, 버전, 설치 상태, 호환성을 읽으세요. **Built in**은 앱에 포함된 패키지를 뜻합니다. 거부된 패키지나 중복 후보도 표시될 수 있으므로 목록에 있다는 이유만으로 활성화되었다고 판단하지 마세요.

사용 가능한 패키지가 바뀌었다면 새로 고침을 누르세요. 통합이 거부되었거나 호환되지 않으면 표시된 이유부터 확인합니다.

## 올바른 범위에 설정 적용

선택한 통합의 **Plugin settings**를 여세요. 사용자 또는 선택한 작업 공간에 적용되는 설정이 있으므로 변경 전에 범위와 프로젝트 맥락을 확인합니다. 작업 공간 설정에는 선택된 작업 공간이 필요합니다.

예를 들어 GitHub는 작업 공간의 새로 고침 간격과 기본 이슈 목록을 제공합니다. **GitHub** 사이드바는 저장소 작업을 열고 **Plugins** 목록은 통합 자체를 설정합니다.

## 앱 플러그인과 에이전트 도구

| 위치 | 용도 |
| --- | --- |
| Plugins 사이드바 | Dure 통합 목록, 호환성과 설정 |
| GitHub 사이드바 | 저장소 이슈, pull request, Projects, 작업 시작 |
| Settings → Agent CLI | 설치된 코딩 에이전트 CLI와 제공자 설정 |
| Settings → Agent tooling | Dure CLI, 훅과 에이전트 통합 설정 |

Dure 플러그인이 제공자 로그인을 자동으로 처리하거나 저장소 접근 권한을 부여하지는 않습니다. 제공자 확장과 MCP 설정은 각 도구에서 관리합니다.

[GitHub 작업](/ko/github-workflows) 또는 [에이전트 조율](/ko/orchestration)로 이어가세요.
