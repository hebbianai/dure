새 에이전트는 기본적으로 터미널 pane으로 열립니다. 제공자의 네이티브 CLI를 사용하므로 해당 도구의 명령과 단축키를 Dure의 작업 화면 안에서 그대로 사용할 수 있습니다.

## 셸에서 검증하기

에이전트 옆에 일반 터미널 pane을 여세요. 작업 폴더를 확인한 뒤 프로젝트 명령을 직접 실행합니다. Node.js 프로젝트라면 다음과 같을 수 있습니다.

```sh
pwd
ls
npm test
```

저장소에 실제로 정의된 명령을 사용하세요. `npm test`는 예시이며 Dure의 필수 명령은 아닙니다.

## 파일 열고 편집하기

프로젝트 파일 탐색기에서 파일을 열어 내장 편집기로 확인하세요. 에이전트나 [Diff 리뷰](/ko/review-and-feedback) 옆에 둘 수 있습니다. 자동 저장은 **Settings → General**에서 확인하고, 에이전트와 같은 파일을 수정한다면 작업을 조율하세요.

## 이미지 붙여넣기와 파일 드롭

에이전트 터미널에 이미지를 붙여넣거나 Finder에서 파일을 드롭하세요. Dure가 터미널에 사용할 파일 경로를 준비합니다. SSH pane에서는 먼저 업로드한 뒤 원격 경로를 넣습니다. 첨부를 지원하는 방식은 제공자에 따라 다릅니다.

준비가 끝난 뒤 프롬프트를 전송하세요. 전송에 실패했다면 먼저 오류를 해결하세요. 경로를 첨부해도 제공자에게 추가 파일 접근 권한이 생기지는 않습니다.

에이전트를 시작하기 전 **⌘N** 작업 입력란에도 스크린샷을 붙여넣거나 드롭할 수 있습니다.

## 터미널과 채팅 보기

Beta 인터페이스에서는 지원되는 제공자와 런타임의 pane에서 Terminal/Chat 컨트롤로 대화 화면을 전환할 수 있습니다. **Settings → General → Default agent pane**을 Chat으로 바꾸지 않으면 새 에이전트는 터미널에서 시작합니다. Basic에서는 각 에이전트가 처음 열린 화면을 유지합니다. 모든 CLI의 화면과 재개 동작이 같다고 가정하지 말고 [제공자별 기능](/ko/providers)을 확인하세요.

글자 크기와 줄 높이는 [모양 설정](/ko/settings), 원격 파일 준비는 [SSH 프로젝트](/ko/remote-and-ssh)를 참고하세요.
