**Space**는 Dure 안에서 이름을 붙여 사용하는 pane 배치입니다. 상단 바에서 Main, Review처럼 작업 단계를 나누고, 사이드바에서 필요한 프로젝트와 에이전트를 찾으세요.

| 항목 | 정리하는 대상 |
| --- | --- |
| 프로젝트 | 로컬 또는 SSH 작업 폴더 |
| 에이전트/세션 | 실행 중인 도구와 대화 |
| Pane | 에이전트, 셸, 파일, 리뷰를 보여 주는 화면 |
| Space | Dure 상단 바에서 선택하는 pane 배치 |

Dure Space와 macOS 데스크톱은 별개입니다. pane을 이동해도 에이전트 계정, 작업 폴더, 대화는 바뀌지 않습니다.

## Space 만들고 전환하기

상단 바의 <strong>+</strong>로 Space를 추가하세요. 탭을 선택하거나 **⌘1–⌘9**로 해당 Space로 전환합니다. 작업을 다시 찾기 쉬운 이름을 붙이세요.

## pane 분할과 균등 정렬

터미널 안에서 우클릭하고 **Split Right** 또는 **Split Down**을 선택해 새 pane을 엽니다. 그곳에서 에이전트나 터미널을 선택하세요. 크기를 고르게 맞추려면 상단 바의 **Balance panes in current Space**를 사용합니다.

분할은 배치에 화면을 추가합니다. 새 작업의 파일을 분리하려면 [전용 worktree](/ko/first-parallel-workflow)를 별도로 선택하세요.

## 기존 pane 이동하기

탭을 대상 pane 위로 드래그하세요. **Split Right** 또는 **Split Down** 표시가 나타날 때까지 기다린 다음 강조된 영역에 놓습니다. Space 사이로 pane을 옮기거나 세션을 더 큰 창 또는 별도 창에서 열 수도 있습니다.
