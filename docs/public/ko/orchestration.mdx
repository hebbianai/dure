에이전트가 진행 상황을 보고하거나 결정을 요청하고 맡긴 작업의 결과를 돌려줘야 할 때 Dure의 조율 통합을 사용하세요. 사용자의 목표와 작업 범위에서 시작합니다.

## 작업 기준 정하기

목표, 허용된 변경, 검증 방법, 사용자에게 물어야 할 시점을 명시하세요. 독립적인 범위라면 다른 에이전트가 조사나 리뷰를 병렬로 맡을 수 있습니다.

## 통합 연결

먼저 Dure CLI의 전역 통합 상태를 확인하세요. `--global` 없이 실행한 `dure integration status`는 현재 폴더를 확인합니다.

```sh
dure integration status --global
dure integration --help
```

지원되는 Codex와 Claude의 전역 제공자 설정에 통합 검색 항목을 설치하려면 다음을 실행합니다.

```sh
dure integration install --global --approve-global-config
dure integration status --global
```

설치는 제공자 설정을 변경합니다. 보고된 변경을 읽고 상태 명령으로 설치 결과를 확인하세요. 코딩 에이전트 제공자를 선택하거나 앱 [플러그인](/ko/plugins)을 설정하는 것과는 별개입니다.

## 알맞은 상호작용 사용

| 상호작용 | 용도 |
| --- | --- |
| Message | 결정 응답 자체가 필요하지 않은 진행 상황, 맥락, 질문, 결과 |
| Decision | 맡긴 작업에 대한 명시적인 답변. 텍스트나 제시된 선택지 사용 |
| 완료 보고 | 작업 결과, 검증과 남은 제한 |

CLI와 MCP 통합은 이 상호작용과 이벤트를 제공합니다. 재연결 시 클라이언트가 확인한 이벤트 위치에서 이어받으므로 이전 이벤트를 모두 새로 처리할 필요가 없습니다.

## 전달받은 결과 검토

변경 파일과 보고된 근거를 확인하세요. 요청된 결정에 답하거나 다음 작업의 방향을 정합니다. 완료 보고가 관련 없는 동작까지 승인하거나 [리뷰](/ko/review-and-feedback)를 대체하지는 않습니다.

실행 시작은 [CLI와 예약](/ko/cli-and-automation), 수정 작업 분리는 [병렬 작업](/ko/first-parallel-workflow)을 참고하세요.
