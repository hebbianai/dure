---
title: "VM 환경"
description: "Pro에서 워크트리별 독립 실행 환경을 만듭니다."
---

Pro를 지원하는 Dure에서 Pro 모드를 선택하면 프로젝트 레시피로 VM이나 컨테이너를 준비할 수 있습니다. Dure가 로컬에서 레시피를 실행하고 SSH 호스트를 등록하면, 기존 흐름으로 환경 내부의 워크트리와 에이전트를 생성합니다.

1. **에이전트 추가**에서 로컬 Git 프로젝트를 고르고 **VM 사용 · Pro**를 선택합니다.
2. 레시피와 이름을 고른 뒤 **환경 준비**를 누릅니다. 레시피는 로컬 인증 정보로 실행되며 유료 리소스를 만들 수 있으므로 먼저 스크립트를 검토하세요.
3. 실행 상태가 되면 **이 환경에서 계속**을 선택하고, SSH 호스트 키를 확인한 뒤 원격 워크트리를 생성합니다.
4. **설정 → VM 환경**에서 중지·재개·삭제합니다. Basic으로 전환해도 기존 환경의 중지와 삭제는 가능합니다.

창을 닫아도 준비는 계속됩니다. 에이전트나 창을 삭제해도 VM은 남습니다. 필요한 변경을 저장하거나 푸시한 뒤 명시적으로 환경을 삭제하세요. 삭제하면 게스트 파일과 세션이 사라질 수 있습니다.

## 로컬 Lima 예제

Lima 1.2 이상, Git, Python 3를 설치하세요. [레시피](/examples/lima/lima.sh)를 프로젝트의 `.dure/lima.sh`에, [매니페스트](/examples/lima/dure.environments.json)를 루트의 `dure.environments.json`에 저장합니다.

Ubuntu VM에 현재 커밋을 복사합니다. 호스트 홈은 마운트하지 않으며, 커밋하지 않은 변경과 로그인 정보는 복사하지 않습니다. 게스트에서 에이전트 CLI를 설치하고 로그인하세요.

레시피 입출력, 실패 복구, CLI 명령은 [영문 계약 문서](/en/vm-environments#recipe-contract)를 참고하세요.
