사이드바의 톱니바퀴로 **Settings**를 여세요. 공개 베타는 Basic 인터페이스를 사용하며 일상적인 설정은 Pro 없이 사용할 수 있습니다.

## 필요한 설정 찾기

| 설정 | 위치 |
| --- | --- |
| 설치 버전과 업데이트 확인 | General |
| 기본 제공자와 제공자 권한 기본값 | General |
| 표시 언어와 편집기 자동 저장 | General |
| 제공자 계정 프로필 | AI provider accounts |
| CLI 감지와 제공자 준비 | Provider |
| Dure CLI와 통합 준비 | Agent tooling |
| 테마, 색 구성표, 터미널 글꼴과 줄 높이 | Appearance |
| 상단 Claude/Codex 사용량 표시 | Appearance |
| 에이전트 알림과 소리 | Notifications |
| 활동과 로컬 제공자 로그의 토큰 사용량 | Stats and usage |
| 진단과 데이터 수집 안내 | Privacy and telemetry |

## 읽기 편한 터미널 만들기

상단 바의 **A−**, <strong>A+</strong>로 터미널 글자 크기를 조절하세요. **Appearance → Terminal font**에서 글꼴과 크기, **Line height**를 설정합니다. 미리보기에서 간격을 확인한 뒤 작업으로 돌아오세요.

## 언어와 알림

**General**에서 영어, 한국어, 중국어, 일본어, 스페인어, 프랑스어, 포르투갈어 중 앱 언어를 고르세요. **Notifications**에서는 집중 중일 때의 처리까지 포함해 알림을 받을 이벤트와 소리를 선택합니다.

## 업데이트와 제공자 선택

Mac 앱 업데이트는 **General → Check for updates**에서 확인합니다. 안내된 다운로드와 설치를 직접 선택하세요. 확인만으로 설치나 재시작을 하지 않습니다. 수동 교체가 필요한 이전 베타는 [Dure 설치와 업데이트](/ko/install)를 따르세요.

제공자 CLI 업데이트와 로그인은 앱 업데이트와 별개입니다. [코딩 에이전트와 계정](/ko/providers)에서 제공자와 계정을 선택하고 작업에 맞게 권한을 정하세요. 화면 배치는 권한을 제한하지 않습니다.
