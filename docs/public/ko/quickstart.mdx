익숙한 프로젝트에서 시작하세요. 에이전트 하나에 명확한 작업을 맡기고, 결과를 읽은 뒤 다음 행동을 결정합니다. 먼저 [Dure를 설치](/ko/install)하고 코딩 에이전트 CLI에 로그인하세요.

## 1. 프로젝트 열기

Dure에 로컬 프로젝트 폴더를 추가하세요. Git 저장소에서는 worktree와 변경 리뷰를 사용할 수 있습니다. 작업을 시작하기 전에 프로젝트를 선택해 올바른 폴더에서 실행되도록 하세요.

기존 대화가 있다면 초기 설정의 가져오기 미리보기에서 대화를 선택하고 Space와 pane 배치를 조절한 뒤 확정할 수 있습니다. 가져오기를 건너뛰고 새 작업부터 시작해도 됩니다.

## 2. ⌘N으로 작업 설명하기

**⌘N**을 눌러 **New agent**를 엽니다. 프로젝트와 제공자를 선택하고 다음과 같이 요청하세요.

```text
이 프로젝트의 테스트 실행 방법을 찾아 관련 명령을 실행해줘.
파일은 수정하지 말고, 결과와 실행하지 못한 검증을 알려줘.
```

파일을 독립적으로 수정할 작업이라면 **Isolate in a dedicated worktree**를 켜세요. 시작 전에 계정과 고급 모델·권한 옵션을 확인하세요. 별도 worktree는 파일을 분리하며 에이전트 권한을 제한하지는 않습니다.

## 3. 시작하고 결과 확인하기

**Enter**를 누르거나 **Start agent**를 클릭합니다. 제공자의 네이티브 CLI가 터미널 pane에서 열립니다. 로그인이나 승인 요청이 있으면 처리하고, 보고된 결과와 언급된 파일을 확인하세요.

수정 작업이라면 [Diff 리뷰](/ko/review-and-feedback)에서 실제 변경과 테스트 결과를 확인하세요. 같은 대화에서 수정할 점이나 다음 작업을 전달합니다.

## 4. 필요할 때 에이전트 추가하기

방금 만든 pane의 터미널 안에서 우클릭하세요. **Split Down** 또는 **Split Right**를 선택한 뒤 새 pane에서 다음 에이전트를 선택합니다.

병렬 수정에는 [독립 worktree](/ko/first-parallel-workflow)를 사용하세요. [GitHub 사이드바](/ko/github-workflows)의 이슈나 pull request에서 **Start**로 시작할 수도 있습니다.

화면을 정리하려면 [Space와 pane](/ko/spaces-and-panes), 기존 대화로 돌아가려면 [세션과 복구](/ko/session-model)를 참고하세요.
